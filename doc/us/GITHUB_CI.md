# GitHub Actions CI

The ncdc cross-interface fixtures reserve ports on both loopback addresses, retaining the conflicting listener until the client is ready. Allocation-only EADDRINUSE collisions choose a fresh pair with bounded retries; test failures are never retried. `integration.ncdc_ports` covers deterministic TCP/UDP collisions and cleanup.

The `Check status` workflow in `.github/workflows/build.yml` runs on GitHub-hosted `ubuntu-22.04`, `ubuntu-24.04` and `ubuntu-26.04`. Stage I beta-0.3.3 removes the assumption of exactly four logical CPUs; jobs use the runner's available `nproc`. Stage II beta-0.3.7 adds TOTP verifier/replay and MFA login tests to the WebAdmin Node suite. Stage III beta-0.3.10 adds HTTPS cipher/header integration checks, optional sandbox constraints and fixed-route private pilot preflight tests. Stage IV beta-0.3.12 adds bounded stress/failure tests, validated nonsecret audit records and a CTest release gate. Pushes to `main`, historical release branches and `beta-0.3.1-12-full` run CI. Pull requests targeting `main` and manual dispatches also run; fork permission behavior is governed by repository settings. The workflow has read-only repository permissions and disables persisted checkout credentials. Use the workflow file for the authoritative branch list.

Two jobs run on each of those three images. C++ Debug, C++ Release and WebAdmin each run once per image, with `nproc` workers. The C++ step runs `dependencies.audit` to check shared libraries, the locked WebAdmin package catalog and registered security tests; it also runs `beta.baseline` for `beta-0.3.12`. See [Dependencies](DEPENDENCIES.md) and [Beta baseline](BETA.md). The WebAdmin job checks high-severity production npm advisories after `npm ci`, then builds, typechecks, runs Node/Chromium and the real C++ API integration on Node.js 22. Two additional Ubuntu 24.04 Debug builds run the instrumented security test subset with ASan and UBSan; their results gate the existing named required CI check. These are not ThreadSanitizer or coverage-guided fuzzing runs. Non-TLS bytes on a TLS port may end as EOF or one fatal alert record; the server still does not call SSL_shutdown().

Concurrency uses one group per workflow and ref, `dc24h-github-` plus the workflow name and ref, with `cancel-in-progress: false`. The C++ job has a 120-minute timeout and the WebAdmin job has a 60-minute timeout. Check each run under [GitHub Actions](https://github.com/adrianf87/dc24h.eu-high-starter/actions/workflows/build.yml) for actual results. CI completion is not awaited.

Push triggers CI; remote completion is not awaited.
