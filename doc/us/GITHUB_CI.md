# GitHub Actions CI

The ncdc cross-interface fixtures reserve ports on both loopback addresses, retaining the conflicting listener until the client is ready. Allocation-only EADDRINUSE collisions choose a fresh pair with bounded retries; test failures are never retried. `integration.ncdc_ports` covers deterministic TCP/UDP collisions and cleanup.

The `Check status` workflow in `.github/workflows/build.yml` runs on public GitHub-hosted runners `ubuntu-22.04`, `ubuntu-24.04` and `ubuntu-26.04`. Each image is specified with four logical CPUs and 16 GB of memory. On a public repository those labels provide that size. On a private repository GitHub documents two logical CPUs and 8 GB for the same labels. GitHub marks `ubuntu-22.04` deprecated and still accepts that label. Pushes to `main`, `alpha-0.8.7`, `alpha-0.8.8`, `alpha-0.8.9`, `alpha-0.8.10`, `alpha-0.8.11`, `alpha-0.8.12`, `alpha-0.8.13`, `alpha-0.8.14`, `alpha-0.8.15`, `alpha-0.9.1`, `alpha-0.9.2`, `alpha-0.9.3`, `alpha-0.9.4`, `alpha-0.9.5`, `alpha-0.9.6`, `alpha-0.9.7`, `alpha-0.9.8`, `alpha-0.9.9`, `alpha-0.9.10`, `alpha-0.9.11`, `alpha-0.9.12`, `alpha-0.9.13`, `alpha-0.9.14`, `alpha-0.9.15`, `alpha-0.9.16`, `alpha-0.9.17` and `beta-0.1`, and manual dispatches, trigger CI. Fork pull requests do not run. The workflow has read-only repository permissions and disables persisted checkout credentials.

Two jobs run on each of those three images. C++ Debug, C++ Release and WebAdmin each run once per image. Each job checks that `nproc` equals 4 and then uses `nproc` workers. The C++ test step also runs `dependencies.audit`, which checks the direct shared libraries of the hub binaries, the exact WebAdmin lockfile and the security tests CMake always registers. That check does not add a job, a sanitizer matrix or a network scan. See [Dependencies](DEPENDENCIES.md). The same step runs `beta.baseline`, which checks the `beta-0.1` release string and the unchanged limits. See [Beta baseline](BETA.md). The C++ job builds and tests Debug and Release, including integration tests, after installing the toolchain, MariaDB, Apache and ncdc. The WebAdmin job builds the Release hub binary, then runs typecheck, the production build, Node tests, Chromium and the live C++ API integration with Node.js 22. Non-TLS bytes on a TLS port may end as EOF or one fatal alert record. A test client close accepts abrupt EOF or a completed unwrap(); the server still does not call SSL_shutdown().

Concurrency uses one group per workflow and ref, `dc24h-github-` plus the workflow name and ref, with `cancel-in-progress: false`. The C++ job has a 120-minute timeout and the WebAdmin job has a 60-minute timeout. Check each run under [GitHub Actions](https://github.com/adrianf87/dc24h.eu/actions/workflows/build.yml) for actual results. CI completion is not awaited.

Push triggers CI; remote completion is not awaited.
