# WebAdmin (planned)

Reserved for React + TypeScript + Vite. No frontend application is implemented in alpha-0.1.9. Apache2 will serve assets and proxy a secured C++ API. See [WebAdmin](../doc/us/WEBADMIN.md).

The local read-only C++ API exists; see [API](../doc/us/API.md). A cross-UID Apache gateway, browser authentication and administrative write operations remain planned. Never ship the service token to frontend JavaScript.
